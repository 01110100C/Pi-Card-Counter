# Raspberry Pi Card Counter

</p>
<h2>Description</h2>
<p>
  This Raspberry Pi Card Counter is able to run a live stream where the user will deal cards from a standard playing deck. It will be able to detect the suit and face value of the card. 
  It will then keep a running count based on the standard for counting cards in BlackJack to give the user advice on what move to make next. The user can input how many
  decks they are playing with and the model will be able to remove all cards seen already. The steam and updating count are displayed on a static web page for easier usability. 
</p>

<h2> Technical Stack </h2>
<ul>
<li> Raspberry Pi 5 </li>
<li> PiCamera </li>
<li> OpenCV: used for real-time computer vision and image processing </li>
<li> Python </li>
<li> HTML/CSS </li>
</ul>
